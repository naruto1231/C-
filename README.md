# C言語：2つの整数の加減算プログラム

標準入力から入力された2つの整数に対して、足し算（加算）と引き算（減算）を計算して結果を出力するシンプルなC言語プログラムです。

## 機能
- ユーザーから整数 `a` と `b` の入力を受け取ります。
- `a + b` の計算結果を出力します。
- `a - b` の計算結果を出力します。

## 動作環境・前提条件
- C言語コンパイラ（GCC, Clang, MSVCなど）

## 実行方法

### 1. コンパイル
ターミナルまたはコマンドプロンプトを開き、以下のコマンドを実行してコンパイルします。

```bash
gcc -o calc main.c
